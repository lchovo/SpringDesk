How to organize your Windows 11 desktop

The desktop is where downloads, screenshots and "I'll sort it later" files end up. Here's how to clear it in about fifteen minutes with what's built into Windows 11, and how to keep it that way.

By Brock Loong · October 22, 2026

1. Clear out what you don't need

Right-click an empty spot on the desktop and choose Sort by › Date modified. The oldest files end up together, and they're usually the easiest to deal with:

  • Installers (Setup.exe, .msi files) can go once the app is installed.
  • Old screenshots and downloads you've already used can go too, or into Pictures or Documents.
  • Documents you're done with belong in Documents, where File Explorer and search can find them.

Deleted files go to the Recycle Bin, so nothing is gone until you empty it.

2. Make folders for what's left

Right-click the desktop, choose New › Folder, and give it a short name: Work, Receipts, This week. Drag files onto a folder to move them in. A few folders with clear names beat many with vague ones.

3. Let Windows line things up

Right-click the desktop and open View:

  • Align icons to grid keeps icons in neat rows wherever you drop them.
  • Auto arrange icons packs them into columns from the top left. It's tidy, but you can't place icons where you want.
  • Small, Medium or Large icons change the size. You can also hold Ctrl and turn the mouse wheel on the desktop.

Sort by › Item type puts folders, then documents, then shortcuts together. To choose which system icons appear (Recycle Bin, This PC), go to Settings › Personalization › Themes › Desktop icon settings.

4. Put apps where you start them

Many installers drop a shortcut on the desktop. If you start the app from Start or the taskbar anyway, delete the shortcut (that only removes the shortcut, not the app). To keep an app close, right-click it in Start and choose Pin to Start or Pin to taskbar. Next time an installer asks about a desktop shortcut, untick it.

5. Stop downloads from piling up

  • Check where your browser saves files. In Edge it's Settings › Downloads › Location, in Chrome Settings › Downloads. The Downloads folder is usually a better place than the desktop.
  • Let Storage Sense clear old downloads. In Settings › System › Storage › Storage Sense, you can have Windows delete files in Downloads that you haven't opened for 14, 30 or 60 days.

6. Hide everything when you need a clean screen

Right-click the desktop and untick View › Show desktop icons before a presentation or screen share. Tick it again to bring them back; nothing moves.

Why do my icons rearrange themselves?

When the screen resolution or scaling changes, for example when you connect to a different monitor, dock a laptop or sign in over Remote Desktop, Windows fits the icons onto the new screen size and they can end up in a different order. Turning off Auto arrange helps a little. Desktop organizers that remember a layout for each display setup avoid it altogether.
