Änderungsprotokoll

Jedes Update für SpringDesk, das neueste zuerst. Updates sind kostenlos und kommen automatisch über den Microsoft Store. Einen Fehler gefunden? Schreib an contact@springdesk.app oder eröffne ein Issue. Jede Meldung wird gelesen, und Fehlerbehebungen erscheinen als Store-Updates.
