Windows 11 바탕 화면 정리 프로그램 비교

Windows 11에는 아직도 바탕 화면 아이콘을 박스로 묶는 기능이 없습니다. 이 기능을 더해 주는 프로그램을 무료와 유료로 나눠, 각각 잘하는 것과 알아 둘 점을 정리했습니다.

작성: Brock Loong (SpringDesk 개발자) · 확인: 2026년 11월 27일

SpringDesk는 제가 만든 앱이니, 그에 대한 평가는 그 점을 감안해 읽어 주세요. 다른 앱은 공식 페이지와 문서에 나온 내용을 정리하고, 직접 확인할 수 있게 링크를 달았습니다. 가격과 기능은 바뀝니다. 오래된 내용이 있으면 알려 주세요.

1. Windows 기본 기능

무언가를 설치하기 전에: 바탕 화면의 폴더, 바탕 화면 오른쪽 클릭 메뉴의 정렬 기준과 아이콘 자동 정렬, 모두 숨기는 바탕 화면 아이콘 표시가 있습니다. 저장소 센스로 오래된 다운로드를 자동으로 지울 수도 있습니다. 아이콘이 몇 개뿐이라면 이걸로 충분하지만, 박스나 탭이 없고 새 파일은 직접 정리해야 합니다. Windows 11 바탕 화면 정리 방법(영어)에서 모두 설명합니다.

2. SpringDesk

제가 만든 앱입니다. 바탕 화면 아이콘을 투명한 유리 박스에 담습니다. 박스는 격자에 맞춰 정렬되고 서로 겹치지 않으며, 탭, 말아 올리기, 배치 잠금을 지원합니다. 바탕 화면에 저장하거나 내려받은 파일은 종류별 탭으로 바로 들어가고, 나머지는 받은 파일함에서 기다리므로 규칙 없이도 바탕 화면이 정리된 상태로 유지됩니다. 스페이스바로 파일을 미리 보고, 바탕 화면을 클릭해 입력하거나 어느 창에서든 Alt+Space를 눌러 모든 박스를 검색할 수 있습니다. 폴더 박스는 어떤 폴더든 바탕 화면에 보여 주고, 하위 폴더도 박스 안에서 바로 엽니다. 바탕 화면을 더블 클릭하면 모든 박스가 숨겨지고, 자리를 비운 동안 자동으로 사라지게 할 수도 있습니다. 하나의 배치가 모든 화면에 맞춰지고, 매일 백업됩니다. 10개 언어를 지원합니다.

알아 둘 점: Windows 11 전용이고, 7일 체험 후 유료입니다. 파일 종류로만 정리하며, 박스마다 색을 다르게 하는 대신 모든 박스가 같은 모양(라이트 또는 다크, 투명 또는 반투명)입니다. 2026년 10월에 처음 나온 새 앱입니다.

Microsoft Store의 SpringDesk

3. Fences 7

Stardock이 만든, 가장 잘 알려진 바탕 화면 정리 프로그램입니다. 아이콘을 ‘펜스’라는 영역으로 묶고, 탭, 말아 올리기, Folder Portals, 파일을 종류·이름·시간·대상별로 정리하는 규칙을 지원합니다. 펜스마다 색상, 투명도, 모서리 모양, 아이콘 색조를 바꿀 수 있고, Peek(Win+Space)로 열린 창 위에 펜스를 불러오며, Quick-hide로 바탕 화면을 비울 수 있습니다. Fences 7(2026년 11월)에는 화면을 공유하는 동안 파일 이름과 아이콘을 가리는 개인 정보 보호 모드, Windows 설정에 따라 라이트와 다크 모드가 바뀌는 Windows 11의 Mica 소재, Folder Portals 안 검색이 추가되었습니다.

알아 둘 점: 구독은 연 US$10이고, Fences 7 영구 라이선스는 US$30입니다.

stardock.com의 Fences · SpringDesk와 Fences 자세히 비교

4. PecoFence

Rust로 만든 무료 오픈 소스 앱(Apache 2.0)으로, Microsoft Store와 GitHub에서 받을 수 있습니다. 처음 실행하면 프로그램, 폴더, 파일 및 문서, 바탕 화면이라는 네 개의 펜스를 만듭니다. Fluent와 Liquid Glass 테마의 유리 펜스, 탭, 말아 올리기, 안을 둘러볼 수 있는 라이브 폴더, 새 파일을 종류·이름·시간·크기별로 정리하는 규칙이 있고, 스마트 펜스는 지난주 다운로드처럼 저장한 검색의 결과를 실시간으로 보여 줍니다. Ctrl+Alt+Space를 누르면 펜스를 다른 창 위로 불러와 검색할 수 있습니다(Everything을 설치하면 PC 전체도 검색). 가상 데스크톱마다 따로 두는 펜스, 매일 백업, 메모·할 일·시계가 있는 플러그인 스토어, AI 코딩 에이전트가 대신 설정해 줄 수 있는 명령줄 도구도 있습니다.

알아 둘 점: 아직 초기 단계(2026년 11월 기준 버전 0.5)라 빠르게 바뀝니다. 스페이스바 미리 보기는 Seer나 QuickLook을 따로 설치해야 쓸 수 있습니다.

GitHub의 PecoFence

5. Desktop Frames+

BirdyFences 프로젝트를 이어받은 무료 오픈 소스 앱입니다. 기능 목록이 깁니다. 바로 가기용 프레임, 폴더 내용을 그대로 보여 주는 포털 프레임, 탭, 들어오는 파일을 프레임으로 옮기는 규칙, 빠른 검색 창, 작업 공간 프로필, 프레임별 색상, 매일 백업이 있습니다. 포터블 앱이라 설치할 필요가 없습니다.

알아 둘 점: GitHub에서 내려받습니다. 옵션이 많은 만큼 설정에 시간이 좀 듭니다.

GitHub의 Desktop Frames+

6. Portals

각각 한 폴더의 내용을 보여 주는 컨테이너(‘포털’)로, 파일을 폴더에 넣는 방식으로 정리합니다. 포털 묶음을 레이아웃으로 저장해 두면 디스플레이 구성이 바뀔 때 자동으로 전환됩니다. 무료이며, 라이선스 키는 Gumroad에서 받습니다. 원하는 만큼 내면 되고, 내지 않아도 됩니다.

알아 둘 점: 바탕 화면 아이콘 자체가 아니라 폴더를 다루는 앱입니다.

portals-app.com

7. Nimi Places

직접 고른 위치의 파일과 폴더를 아이콘이나 미리 보기 이미지로 보여 주는, 꾸밀 수 있는 컨테이너입니다. 미디어를 미리 볼 수 있는 플레이어도 들어 있습니다. 2010년부터 개발되어 지금도 업데이트되며(최근 2026년 11월), 테마와 스타일 옵션이 많습니다.

알아 둘 점: 컨테이너마다 위치를 직접 설정해야 하고, 모양은 Windows 11풍이 아닌 독자적인 스타일입니다.

mynimi.net의 Nimi Places

8. iTop Easy Desktop

바탕 화면 파일을 자동으로 묶는 박스, 암호로 보호되는 비공개 박스, 폴더 포털, 더블 클릭으로 아이콘 숨기기에 더해, 위젯(달력, 시계, 메모, 날씨), 배경 화면 라이브러리, AI 채팅 도우미까지 갖추고 있습니다.

알아 둘 점: 무료 버전은 박스 3개까지입니다. Pro는 연간 또는 평생 요금제입니다(2026년 11월 할인가 기준 연 US$11.99). 아이콘 정리 외에도 기능이 많습니다.

itopvpn.com의 iTop Easy Desktop

고르는 법

  • 무료가 좋다면: 규칙과 검색이 있는 유리 펜스를 원하면 PecoFence, 모든 옵션을 갖고 싶으면 Desktop Frames+, 폴더 단위로 정리한다면 Portals, 꾸미기가 중요하면 Nimi Places.
  • Windows 10을 쓴다면: Fences 또는 무료 앱 중 하나. SpringDesk는 Windows 11이 필요합니다.
  • 세세하게 제어하고 싶고 구독도 괜찮다면: Fences.
  • 투명한 유리 박스, 설정 없이 정리되는 새 파일, 다른 앱 없이 스페이스바 미리 보기, 한 번만 결제를 원한다면: SpringDesk. 7일 무료 체험.

무엇을 고르든 바탕 화면 정리 프로그램은 한 번에 하나만 실행하세요. 모두 같은 아이콘을 관리하기 때문에 서로 방해가 됩니다.

SpringDesk 7일 무료 체험

Windows 11용. 체험 후 한 번만 결제하며, 구독은 없습니다.
