변경 기록

SpringDesk의 모든 업데이트를 최신순으로 정리했어요. 업데이트는 무료이며 Microsoft Store를 통해 자동으로 전달돼요. 버그를 찾으셨나요? contact@springdesk.app으로 이메일을 보내거나 이슈를 등록해 주세요. 모든 제보를 확인하며, 수정 사항은 Store 업데이트로 제공돼요.

  • 새 기능: 밝게와 어둡게: 설정 › 모양 › 테마에서 밝게, 어둡게 또는 자동을 고르세요. 자동은 Windows를 따릅니다.
  • 개선: 설정 › 일반 › 바탕 화면에 ‘바탕 화면 아이콘 표시’와 ‘Windows 기본 아이콘도 함께 표시’가 나란히 놓였습니다.
  • 개선: 각 박스의 메뉴가 아니라 알림 영역 아이콘에서 설정을 엽니다.

1.0.0 · 2026년 10월 16일

  • 새 기능: GitHub 무료 빌드로 첫 출시. 이전 이름 DeskFlow, 현재 SpringDesk. Windows 11이 필요합니다.
  • 새 기능: 박스를 만들고, 이름을 바꾸고, 옮기고, 크기를 조절하고, 제목 표시줄만 남기고 말아 올립니다.
  • 새 기능: 탭: 한 박스 안에 여러 아이콘 그룹을 넣고, 박스를 다른 박스 제목 표시줄에 놓아 합칩니다.
  • 새 기능: 폴더 박스: 다운로드 같은 폴더를 보여 주는 박스입니다.
  • 새 기능: 처음 사용할 때 바탕 화면을 앱, 파일, 폴더, 다운로드로 정리하고 불분명한 항목은 받은 파일함에 넣습니다. 바탕 화면의 새 파일은 종류별로 제자리를 찾습니다.
  • 새 기능: 박스가 격자에 맞춰지고 겹치지 않습니다. 실수로 끌리지 않게 배치를 잠급니다.
  • 새 기능: 최근에 연 아이콘이 맨 앞으로 이동하며, 아이콘에 마우스를 대면 Windows와 같은 세부 정보가 보입니다.
  • 새 기능: 바탕 화면이나 박스를 클릭해 바로 입력하면 검색되며, 중국어 이름의 병음 첫 글자도 찾습니다. 또는 언제든 Ctrl+Alt+Space를 누르세요.
  • 새 기능: 모양, 잠금, 배치 백업을 위한 제어 센터.
  • 새 기능: 설치 프로그램. SpringDesk는 Windows와 함께 시작하며, 업데이트는 한 번 클릭해 다시 시작하면 적용됩니다.
  • 새 기능: 문제가 생겼을 때 보낼 수 있도록 제어 센터 › 정보에서 진단 정보를 내보냅니다.
  • 새 기능: DeskFlow에서 업그레이드해도 박스가 유지됩니다.
