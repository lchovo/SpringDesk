How to preview files with Spacebar on Windows 11

If you've used a Mac, pressing Space to look inside a photo, PDF or video without opening a heavy app becomes muscle memory. Windows 11 doesn't bind the Space bar to Quick Look out of the box, so here are the four ways to get instant file previews, depending on where you keep your files.

1. Built into Windows 11: File Explorer's Preview Pane

Before installing anything, open File Explorer, select View › Show › Preview pane (or press Alt+P). Clicking an image, text file or PDF shows a small preview in the right-hand column.

Good for: Skimming documents inside a folder window with zero extra software.
Keep in mind: It takes up horizontal space in File Explorer, doesn't play video or audio inline, and doesn't work on the desktop itself.

2. Official Microsoft utility: PowerToys Peek

Microsoft's free PowerToys suite includes a module called Peek. Once installed, select a file in File Explorer and press Space. That's the default since PowerToys 0.95 (older versions used Ctrl+Space), and you can change it in PowerToys settings. The arrow keys move to the next file and Enter opens it.

Good for: Users who already run PowerToys for FancyZones or PowerToys Run and want Space preview in File Explorer.

3. Free single-key Spacebar utility: QuickLook

QuickLook is a popular open-source app in the Microsoft Store and on GitHub that brings single-key Space preview to File Explorer and the standard Windows desktop, with optional plugins for Office files and archives.

Good for: Keeping the standard Windows desktop and File Explorer, while adding Mac-style Space preview everywhere for free.

4. Spacebar preview + an organized desktop: SpringDesk

I built SpringDesk for people whose working files (downloads, screenshots, PDFs, project folders) live on the Windows 11 desktop. It gathers your desktop icons into clear glass boxes, sorts new files into tabs by type automatically, and builds Space preview directly into every box and folder box:

  • Instant opening, zero app spin-up: Select any icon and press Space. Photos (with mouse-wheel zoom), PDFs (rendered with Windows 11's native engine), videos, audio, plain text and source code open right away.
  • Arrow-key browsing: Leave the preview open and press the arrow keys to flip through the rest of the tab; neighboring photos decode ahead so there's no pause.
  • Honest speed on heavy formats: Rather than calling Word or Excel in the background and making you wait, Office files, archives and installers show a fast details card with size, item count and timestamps, and Enter opens the full file when you need it.
  • Works on any folder, too: Pin your Downloads or project folder onto the desktop as a folder box, open subfolders right inside it, and press Space on anything there.

Keep in mind: SpringDesk previews files inside its desktop boxes and folder boxes, not inside separate File Explorer windows, and it requires Windows 11.

Questions

Does Windows 11 have Mac's Spacebar Quick Look built in?

Not out of the box. Windows 11 has File Explorer's side Preview Pane (Alt+P). Microsoft PowerToys adds Peek, which previews the file selected in File Explorer when you press Space (Ctrl+Space before PowerToys 0.95). For Space preview on the desktop itself, you need an app such as QuickLook or SpringDesk.

What file types can SpringDesk preview with Space?

Pictures, videos, music, plain text, code and PDFs open directly in the preview window. Word, Excel, PowerPoint, zip archives, installers, shortcuts and folders show an instant info card.

Does SpringDesk move my files?

No. Your files stay in your Desktop folder (or their own folder in a folder box). Quit or uninstall SpringDesk and your Windows 11 desktop is back just as it was. See how to organize your Windows 11 desktop and desktop organizers compared.
