专为 Windows 11 而生

透明玻璃贴着壁纸，跟随浅色深色，右键就是 Windows 自己的菜单。看起来就像系统自带的。

自己保持整齐

第一次打开就把桌面整理好，之后每个新文件都会自己归位。什么都不用设置。

一次买断

付一次钱，以后的更新全包含。不订阅，也不用注册账号。

通透得像不存在

图标住进透明玻璃分区，贴着壁纸，待在所有窗口下面。只有边缘映着光，壁纸完整地透出来，动态壁纸也一样。它看起来是 Windows 11 的一部分，用起来也一样：双击打开、右键菜单、拖放、F2 改名，全都照旧。

新文件，自己找到家

第一次打开，SpringDesk 就把桌面整理成软件、文件、文件夹和下载几个分区。之后保存或下载到桌面的文件，直接进对应的标签页：文档、表格、演示文稿、PDF、图片。不用写任何规则；分不清的先放进临时分区，什么都不会丢。

文件夹不用开，专注不用断。

文件夹门户把一个文件夹里的东西（比如"下载"、"文档"或手头的项目）直接铺在桌面上。不是快捷方式，是文件本身，多了少了实时跟上，文件一个都不用复制或挪动。可以按名称、日期或类型排序，双击打开，像在文件资源管理器里一样拖进拖出；搜索也能找到里面的文件。

按下空格，一眼看穿

图片、视频、音乐、文本、代码和 PDF，瞬间打开，不用启动任何软件，就像 Mac 上的"快速查看"。方向键切到下一个；其他文件也能一眼看到基本信息。

想找什么？直接打字

点一下桌面，敲几个字；或者在任何地方按 Ctrl+Alt+空格。所有分区和标签页边打边搜，放在桌面上的文件夹里的也算。中文名用拼音全拼或首字母就行。

收放自如

把一个分区拖到另一个上，就合成标签页，点一下切换。需要地方时把分区卷起，只留标题栏；锁定布局，不怕误拖。分区对齐网格、从不重叠，怎么挪都整齐。

浅色、深色，还有雾面

跟随 Windows 的浅色和深色模式。壁纸太花？调低透明度，玻璃就变成雾面，名字更醒目。

表面通透，内里稳妥。

SpringDesk 只是把桌面整齐地显示出来。退出它，Windows 自己的桌面原样回来。

常见问题

多少钱？

可以先免费试用 7 天，之后在微软商店一次买断，以后的更新全包含，不订阅。中国大陆早鸟价 18 元（原价 28 元），到 2027 年 1 月 1 日；其他地区以商店显示的价格为准。

桌面上的文件会被移走吗？

不会。文件一直在原来的桌面文件夹里，SpringDesk 只是把它们显示在分区里。卸载后桌面和原来一样。

支持 Windows 10 吗？

不支持。SpringDesk 只为 Windows 11 而做，所以能和系统融为一体：跟随 Windows 11 的浅色和深色模式，右键就是 Windows 自己的菜单。

在用别的桌面整理工具，能换过来吗？

可以。先退出原来的工具（检测到 Fences 在运行时，SpringDesk 会提醒你退出），再打开 SpringDesk，它会把桌面按类型整理进分区，之后随意调整。其他软件的布局不能导入。

还在持续更新吗？

是的。2026 年 10 月 17 日上架微软商店后，第一周就更新了十几次，大多是按用户反馈做的修复和改进。每次的改动都在更新日志里（英文），更新由微软商店自动安装。

安全软件（360、火绒等）弹出提示？

"在桌面上打字就搜索"需要接收键盘输入，有的安全软件会提示，选择允许就行。不想用这个功能，可以在 设置 › 通用 里关掉。

会收集我的数据吗？

不会。没有账号、没有广告、不收集数据，一切都在你的电脑上完成。见隐私政策。

遇到问题怎么办？

打开 设置 › 关于 › 导出诊断信息，把压缩包附在 GitHub Issues 里，或发邮件到 contact@springdesk.app。里面是日志和分区布局，有桌面上的文件名，没有文件内容。
