让 Windows 11 桌面
自己保持整齐

SpringDesk 把桌面图标放进透明的分区，对齐网格；新文件按类型自动归位；不用打开就能预览，打字就能找到。

免费试用 7 天 · 一次买断，不订阅

分区不挡路

图标放在壁纸上的透明分区里，在所有窗口下面。把图标拖进来，其他图标自动让位。分区对齐网格、不会重叠，怎么挪桌面都整齐。

标签页，还能卷起

把一个分区拖到另一个上面，就合并成标签页，点一下切换。需要空间时把分区卷起，只留标题栏；锁定布局，免得误拖。

新文件自动归位

保存或下载到桌面的文件，直接进对应的标签页：文档、表格、演示文稿、PDF、图片等。分不清的放进临时分区，什么都不会丢。

按空格看一眼

图片、视频、音乐、文本、代码和 PDF 立刻打开，不用启动别的软件；方向键看下一个。其他文件显示基本信息。

直接打字就能找

点一下桌面直接打字，或在任何地方按 Ctrl+Alt+空格。所有分区和标签页里的东西都能搜到，中文名用拼音全拼或首字母也行。

浅色深色，透明玻璃

跟随 Windows 的浅色和深色模式。分区是透明玻璃，只有边缘透光，名字在任何壁纸上都看得清。调低透明度就变成雾面；动态壁纸也跟得上。

和 Windows 一样用

双击打开，右键是熟悉的菜单，拖放、剪切、复制、粘贴，F2 改名。

布局不会乱

每种分辨率和缩放各存一份布局，每天自动备份，随时可以恢复。

文件不动

SpringDesk 只是把桌面整齐地显示出来，不移动、不删除任何文件。

不收集数据

没有账号、没有广告、不收集数据，一切都在你的电脑上。

常见问题

多少钱？

可以先免费试用 7 天，之后在微软商店一次买断，更新都包含，不订阅。中国大陆早鸟价 18 元（原价 28 元），到 2027 年 1 月 1 日；其他地区以商店显示的价格为准。

桌面上的文件会被移走吗？

不会。文件一直在原来的桌面文件夹里，SpringDesk 只是把它们显示在分区里。卸载后桌面和原来一样。

支持 Windows 10 吗？

不支持，SpringDesk 需要 Windows 11。

在用别的桌面整理工具，能换过来吗？

可以。先退出原来的工具（检测到 Fences 在运行时，SpringDesk 会提醒你退出），再打开 SpringDesk，它会把桌面按类型整理进分区，之后随意调整。其他软件的布局不能导入。

安全软件（360、火绒等）弹出提示？

"在桌面上打字就搜索"需要接收键盘输入，有的安全软件会提示，选择允许就行。不想用这个功能，可以在 设置 › 通用 里关掉。

会收集我的数据吗？

不会。没有账号、没有广告、不收集数据，一切都在你的电脑上完成。见隐私政策。

遇到问题怎么办？

打开 设置 › 关于 › 导出诊断信息，把压缩包附在 GitHub Issues 里，或发邮件到 SpringDesk@outlook.com。里面是日志和分区布局，有桌面上的文件名，没有文件内容。
