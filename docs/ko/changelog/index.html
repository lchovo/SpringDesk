변경 기록

SpringDesk의 모든 업데이트를 최신순으로 정리했어요. 업데이트는 무료이며 Microsoft Store를 통해 자동으로 전달돼요. 버그를 찾으셨나요? contact@springdesk.app으로 이메일을 보내거나 이슈를 등록해 주세요. 모든 제보를 확인하며, 수정 사항은 Store 업데이트로 제공돼요.

최신 버전: 1.15.1, 2026-11-24

1.15.1 · 2026년 11월 24일

  • 새 기능: SpringDesk가 10개 언어를 지원합니다. English, Deutsch, Español, Français, Italiano, Português (Brasil), 日本語, 한국어, 简体中文, 繁體中文입니다. Windows 표시 언어를 따르며, 설정 › 일반 › 언어에서 다른 언어를 고를 수도 있습니다. SpringDesk가 붙인 기본 박스와 탭 이름(받은 파일함, 즐겨찾기, 탭 2…)은 언어에 맞춰 바뀌며, 사용자가 직접 입력한 이름은 그대로 유지됩니다.
  • 개선: 검색 시 악센트 부호를 구분하지 않아 ‘resume’을 입력하면 ‘Résumé’를 찾습니다.
  • 수정: 창이 열려 있는 상태에서 바탕 화면 보기(Win+D 또는 작업 표시줄 맨 오른쪽 끝)를 사용할 때 박스가 잠깐 깜빡일 수 있었습니다. 이제 깜빡이지 않고 안정적으로 유지됩니다.

  • 새 기능: SpringDesk를 다시 설치한 뒤 박스를 복원할 수 있습니다. SpringDesk는 문서 › SpringDesk에 배치 사본을 보관하며, 다시 설치하면 박스를 되돌릴지 묻습니다.
  • 개선: 박스 안의 ‘정렬 기준’이 Windows 바탕 화면과 동일하게 동작하며 ‘크기’가 추가되었습니다. 이름, 크기, 유형 또는 수정한 날짜를 선택하면 한 번 정렬되고, 바로 이어서 같은 항목을 다시 선택하면 순서가 뒤집힙니다.
  • 개선: ‘최근에 연 순서’가 ‘정렬 기준’ 아래의 스위치로 바뀌었습니다(박스 빈 곳 오른쪽 클릭 › 정렬 기준 › 최근에 연 순서). 이번 업데이트 후에는 꺼져 있으므로 필요한 박스에서 켜세요.
  • 개선: 바탕 화면 오른쪽 클릭 메뉴가 짧아졌습니다. ‘붙여넣기’는 붙여넣을 항목이 있을 때만 표시되며, ‘SpringDesk 사용’과 ‘설정’은 알림 영역의 SpringDesk 아이콘 메뉴에 있습니다.
  • 개선: 바탕 화면에 새로 생긴 파일은 항상 해당 박스의 맨 앞에 놓입니다.
  • 개선: SpringDesk가 예기치 않게 종료되거나 설치 프로그램에 의해 닫히면 자동으로 다시 열리며, 응답하지 않을 때는 시작 메뉴에서 다시 열어 기다리거나 재시작할 수 있습니다.
  • 개선: SpringDesk가 바쁠 때도 바탕 화면 응답성이 유지되며, 박스를 처음 끌 때 끊기지 않고, 종료할 때 멈추지 않습니다.
  • 수정: 게임이 테두리 없는 전체 화면으로 실행되는 동안 바탕 화면 보기(Win+D)가 반응하지 않던 문제를 수정했습니다. 이제 다시 작동합니다.
  • 수정: WeGame 경기 결과 같은 팝업 창이 박스 뒤에 가려질 수 있었습니다. 이제 위에 표시됩니다.
  • 수정: 독을 다시 연결하거나 가상 디스플레이가 생겼다 사라진 뒤 박스가 화면 밖으로 이동할 수 있었습니다. 이제 원래 화면에 머뭅니다.
  • 수정: 바탕 화면 폴더가 늦게 연결되면 파일이 박스 안의 자리를 잃을 수 있었습니다. 이제 자리를 유지합니다.

  • 새 기능: 박스 설정이 설정 › 박스에 별도 페이지로 마련되었습니다. ‘자동 분류’ 스위치와 ‘파일 형식’ 목록에서 분류 박스에 탭을 만들 파일 종류를 고르거나 바탕 화면의 탭 메뉴에서 전환할 수 있습니다. 형식을 끄면 해당 탭이 닫히고 안의 파일은 받은 파일함으로 돌아갑니다.
  • 개선: 설정 문구를 더 짧고 알아보기 쉽게 다듬고, 자세한 설명은 각 설정 이름 옆의 작은 ‘?’ 아이콘 안으로 옮겼습니다.
  • 수정: 해상도나 배율을 바꾸거나 다른 기기에서 원격으로 연결할 때 박스가 화면 가운데로 밀리거나 폭이 좁아져 사이에 빈틈이 생길 수 있었습니다. 이제 박스가 정렬을 유지합니다.

  • 수정: Wallpaper Engine 같은 움직이는 배경 화면을 사용할 때 파일 탐색기나 배경 화면 앱이 다시 시작된 뒤 박스를 끌면 반투명 유리를 통해 배경이 비치지 않을 수 있었습니다. 이제 계속 비쳐 보입니다.

  • 새 기능: 박스에 투명한 유리 외관을 적용했습니다. 기본값인 100% 투명도에서는 색조나 흐림 없이 완전히 투명하며 빛을 받는 테두리만 보입니다.
  • 새 기능: 박스에 마우스를 대면 포인터와 가장 가까운 가장자리가 밝아지고 부드러운 빛이 따라옵니다.
  • 새 기능: 말아 올린 박스는 바탕 화면에 이름만 보여 주다가 마우스를 대면 유리 띠를 드러냅니다.
  • 새 기능: 설정 › 모양에서 ‘유리’와 ‘불투명도’를 하나의 ‘투명도’ 슬라이더로 통합했습니다. 값을 낮추면 유리가 뿌옇게 되어 복잡한 배경 화면에서도 읽기 쉬워지며, 기존 모양은 그대로 이어집니다.
  • 개선: 박스와 아이콘 이름에 흰색 글자와 부드러운 어두운 윤곽 빛을 적용해(매우 밝은 배경 화면에서는 거의 검은색으로 전환) 어떤 배경에서도 글자를 읽기 쉽습니다.

1.4.9 · 2026년 10월 20일

  • 개선: 바탕 화면의 ‘보기’ 메뉴에 있는 ‘바탕 화면 아이콘 표시’가 1.4.8 이전처럼 동작하며 끄면 박스도 숨깁니다.
  • 개선: SpringDesk를 종료하면 파일 탐색기가 바쁠 때도 Windows 바탕 화면 아이콘을 즉시 복원합니다.
  • 개선: 바탕 화면에서 ‘새로 만들기’로 만든 항목은 이전처럼 이름 바꾸기 상태로 바로 열리며, 바탕 화면에 저장하거나 다운로드한 파일은 자동으로 이름 바꾸기를 시작하지 않습니다.
  • 수정: 일부 PC에서 박스 뒤쪽의 Windows 자체 바탕 화면 아이콘이 깜빡일 수 있었습니다. SpringDesk는 더 이상 Windows의 ‘바탕 화면 아이콘 표시’ 설정을 바꾸지 않으며 1.4.8에서 바뀐 설정을 복원합니다.
  • 수정: 다른 컴퓨터나 원격 세션에서 끌어온 파일을 빈 바탕 화면에 놓을 수 없던 문제를 수정했습니다. 이제 다시 놓을 수 있습니다.

1.4.8 · 2026년 10월 20일

  • 새 기능: 바탕 화면에서 ‘새로 만들기’ 또는 Ctrl+Shift+N으로 만든 항목이 해당 박스 안에서 이름 바꾸기 상태로 바로 열립니다.

  • 개선: SpringDesk를 끄거나 종료하면 Windows 바탕 화면 아이콘이 원래 있던 정확한 자리로 돌아가며, 새 파일은 Windows가 새 아이콘을 두는 곳에 놓입니다.
  • 개선: Windows에서처럼 바탕 화면 전체에서 선택 상태가 공유됩니다.
  • 개선: 파일 형식을 여는 기본 프로그램을 바꾸면 박스 아이콘이 바로 업데이트됩니다.
  • 개선: 오른쪽 클릭 메뉴가 마우스 단추를 놓는 순간에 표시됩니다.
  • 개선: 트레이 메뉴의 모양을 박스 메뉴와 통일했습니다.
  • 개선: 다운로드 용량을 줄였습니다.
  • 수정: 파일 탐색기가 다시 시작될 때 SpringDesk가 멈추거나 메뉴를 연 채 종료할 때 멈출 수 있었습니다. 이제 두 경우 모두 원활하게 응답합니다.

1.4.7 · 2026년 10월 19일

  • 수정: 빈 바탕 화면을 클릭한 뒤 Ctrl+A, Delete 또는 Enter를 누르면 숨겨진 Windows 바탕 화면 아이콘에 적용될 수 있고, 작업 관리자에서 SpringDesk를 끝내면 아이콘이 숨겨진 채 남을 수 있었습니다. 이제 바로 가기 키가 숨겨진 아이콘에 영향을 주지 않으며 바탕 화면 아이콘이 즉시 돌아옵니다.
