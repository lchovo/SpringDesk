常見問題

還有別的問題？寫信到 contact@springdesk.app。

多少錢？

可以先免費試用 7 天，之後在 Microsoft Store 一次買斷，往後的更新全包含，不訂閱。台灣早鳥價 NT$135（原價 NT$203），至 2027 年 1 月 1 日；其他地區以商店顯示的價格為準。

桌面上的檔案會被移走嗎？

不會。檔案一直在原來的桌面資料夾裡，SpringDesk 只是把它們顯示在分區裡。解除安裝後桌面和原來一樣。

支援 Windows 10 嗎？

不支援。SpringDesk 只為 Windows 11 而做，所以能和系統融為一體：跟隨 Windows 11 的淺色和深色模式，右鍵就是 Windows 自己的選單。

和 Fences 有什麼不同？

Fences 是最知名的桌面整理工具，選項更多，例如自訂排序規則、每個區域的顏色，也支援 Windows 10。SpringDesk 走的是另一條路：為 Windows 11 打造的透明玻璃、新檔案不必設定就按類型歸位、按空白鍵看檔案內容、在桌面上打字就能找到，而且只付一次，比 Fences 一年的訂閱還便宜。看完整比較（英文）。

在用別的桌面整理工具，能換過來嗎？

可以。先結束原來的工具（偵測到 Fences 在執行時，SpringDesk 會提醒你結束），再打開 SpringDesk，它會把桌面按類型整理進分區，之後隨意調整。其他軟體的版面配置無法匯入。

會收集我的資料嗎？

不會。沒有帳號、沒有廣告、不收集資料，一切都在你的電腦上完成。見隱私權政策（英文）。

還在持續更新嗎？

是的。SpringDesk 一直有人維護：問題會修，接下來做什麼也看大家的回饋。哪裡用著不順手，寫信到 contact@springdesk.app。每次的改動都在更新日誌裡（英文），更新由 Microsoft Store 自動安裝。

有繁體中文介面嗎？

還沒有。SpringDesk 的介面目前是英文和簡體中文，跟隨 Windows 的顯示語言：繁體中文的 Windows 會顯示簡體中文，也可以在設定裡改成英文。

遇到問題怎麼辦？

打開 SpringDesk 的「设置 › 关于 › 导出诊断信息」（介面為簡體中文），把壓縮檔附在 GitHub Issues 裡，或寄到 contact@springdesk.app。裡面是記錄檔和分區版面配置，有桌面上的檔案名稱，沒有檔案內容。
