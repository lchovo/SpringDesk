알아서 정돈

새 파일은 스스로 제자리로.

막 받은 다운로드도, 방금 저장한 문서도 각자의 탭으로 들어가요. 설정도 규칙도 필요 없고, 잃어버리는 것도 없어요.

맑은 유리

있는 줄도 모를 만큼 맑게.

빛나는 건 가장자리뿐이라 배경 화면이 온전히 보여요. 움직이는 배경 화면도요.

Space

안이 궁금하면, 스페이스.

스페이스 키 한 번이면 사진, PDF, 동영상이 바로 보여요. 화살표 키로 다음 파일을 넘겨 보세요.

Alt+Space

뭔가 찾고 있나요? 그냥 입력하세요.

바탕 화면을 클릭하고 이름을 입력하거나, 어디서든 Alt+Space를 누르세요. 다 입력하기도 전에 나타나요.

폴더 박스

탐색기는 건너뛰고, 집중은 그대로.

다운로드 폴더나 진행 중인 프로젝트를 배경 화면 위에 열어 두세요. 하위 폴더도 박스를 떠나지 않고 들어가요.

말아 올리기

화면 공유도 여유롭게.

회의 전에 박스를 말아 올리면 화면이 깨끗해져요. 클릭 한 번이면 바탕 화면이 남겨 둔 그 자리 그대로 돌아와요.

그 밖에도

작은 것까지 세심하게.

  • 더블클릭 한 번에 깨끗하게바탕 화면을 더블클릭하면 박스가 모두 비켜서요. 한 번 더 하면 돌아와요.
  • 자리를 비우면, 배경 화면만잠시 자리를 비우면 박스가 서서히 사라지고 배경 화면만 남아요. 돌아오면 바로 다시 나타나요.
  • 겹치면 탭으로박스를 다른 박스 위에 놓으면 한 지붕 아래 모여요.

한 번 결제

평생 내 것.

한 번만 결제하면, 앞으로의 업데이트도 모두 포함돼요.

자주 묻는 질문

더 궁금한 점은 contact@springdesk.app으로 보내 주세요.

가격은 얼마인가요?

7일 동안 무료로 써 볼 수 있어요. 그다음에는 Microsoft Store에서 한 번만 결제하면 되고, 모든 업데이트가 포함되며 구독은 없어요. 한국의 출시 기념 가격은 2027년 1월 1일까지 ₩5,000(정가 ₩7,500)이고, Store에는 사는 나라의 통화로 표시돼요.

SpringDesk가 파일을 옮기나요?

아니요. 파일은 바탕 화면 폴더에 그대로 있고, SpringDesk는 박스 안에 보여 줄 뿐이에요. 제거하면 바탕 화면은 원래대로예요.

Windows 10에서도 되나요?

아니요. SpringDesk는 Windows 11 전용이라 Windows 11과 하나처럼 어울려요. 라이트 모드와 다크 모드를 따르고, 오른쪽 클릭 메뉴도 Windows 자체의 메뉴를 써요. Windows 10에서는 실행되지 않아요.

Fences와 무엇이 다른가요?

Fences는 가장 잘 알려진 바탕 화면 정리 앱으로, 사용자 정렬 규칙과 영역별 색상 같은 옵션이 더 많고 Windows 10에서도 돌아가요. SpringDesk는 다른 길을 택했어요. Windows 11을 위한 투명한 유리, 설정 없이 종류별로 정리되는 새 파일, 스페이스 키로 들여다보는 파일 속, 바탕 화면에서 입력만 하면 되는 검색. 이 모든 것을 Fences 구독 1년보다 저렴한 한 번의 결제로 누릴 수 있어요. 자세한 비교 보기

Fences나 다른 정리 앱을 쓰고 있어요. 바꿀 수 있나요?

네. 먼저 다른 정리 앱을 종료하고(Fences가 실행 중이면 SpringDesk가 알려 줘요) SpringDesk를 실행하세요. 처음 실행할 때 바탕 화면을 박스로 정리해 주니, 그다음엔 원하는 대로 배치하면 돼요. 다른 앱의 레이아웃은 가져올 수 없어요.

내 데이터를 수집하나요?

아니요. 계정도 광고도 데이터 수집도 없어요. 모든 것이 내 PC 안에서 이루어져요. 개인정보 처리방침(영어)을 확인해 보세요.

SpringDesk는 계속 개발되나요?

네. SpringDesk는 꾸준히 관리되고 있어요. 문제는 고치고, 다음에 무엇을 만들지는 보내 주신 의견으로 정해요. 기대와 다르게 동작하는 부분이 있으면 contact@springdesk.app으로 알려 주세요. 모든 변경 사항은 변경 기록에 있고, 업데이트는 Store를 통해 자동으로 설치돼요.

한국어를 지원하나요?

네. SpringDesk는 한국어와 9개 언어를 더 지원하며 Windows 표시 언어를 따라가요. 설정 › 일반 › 언어에서 다른 언어를 고를 수도 있어요.

제대로 작동하지 않아요.

SpringDesk에서 설정 › 정보 › 진단 정보 내보내기를 열고, zip 파일을 첨부해 GitHub에 이슈를 남기거나 contact@springdesk.app으로 보내 주세요. 로그와 레이아웃이 들어 있고, 파일 이름은 있지만 파일 내용은 없어요.
